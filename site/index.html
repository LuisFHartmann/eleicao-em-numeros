Um experimento de estatística com a eleição presidencial

Este site usa os dados públicos do TSE para pôr à prova algumas ferramentas de estatística: como o país votou no 1º turno, por que a apuração parece "virar" durante a noite, o que as eleições passadas sugerem para o 2º turno e, no domingo, para onde a contagem está indo. Código aberto e contas à vista, para quem quiser conferir ou discordar.

Antes de começar: o que este site é, e o que não é

  • É um experimento de estatística. Uma ferramenta de aprendizado pessoal do autor, para experimentar simulação de Monte Carlo (sortear milhares de cenários possíveis), inferência ecológica (estimar como grupos de eleitores mudaram de voto a partir dos totais de cada município), modelos bayesianos (corrigir uma estimativa à medida que chegam dados novos) e as outras ferramentas usadas aqui.
  • A eleição é o estudo de caso. Ela serve de caso de teste para entender o poder, e os limites, dessas ferramentas para prever esse tipo de situação.
  • Não há preferência por nenhum candidato. O trabalho é puramente estatístico e matemático. As cores seguem a convenção usada pela imprensa (vermelho para o 13, historicamente a cor do PT, partido do Lula; azul para o 22, cor usada em geral para o candidato mais à direita) e não indicam preferência.
  • O que fica de fora. Debates, notícias, apoios e outros acontecimentos entre o 1º e o 2º turno mudam o resultado e não são levados em conta neste estudo.
  • O resultado oficial é sempre o do TSE. Simulações e projeções daqui são estimativas com margem de erro, não resultado.
